# Problem Set 0

## "In a short paragraph, tell us what your Scratch project does and/or how to use it (especially if it requires keyboard or mouse input). " -CS50

This game is intended for the user to use their keyboard to move a Wizard toad around the swamp(Screen) to collect Dragonflies until the toad is full. Move the toad around the screen by using the WASD keys. When the toad intersects with a dragonfly the score is increased by one until the user collects 10. Once the user has collected 10 bugs, the game will thank the user and end.
